The problem

Heritage and geography are still taught from flat maps and lists of names. Students memorise places they never get to explore, and most map apps still expect a mouse, a keyboard and patience.

The approach

Put India's heritage on a living 3D globe, then take the mouse away. Hand tracking lets you fly, zoom and select in mid-air, while an LLM guide, live news and weather give every monument context.

Decisions

Three engineering calls

01

Moving hand tracking into the browser

The first version streamed base64-encoded webcam frames to a Python worker. I ported the gesture classifier to JavaScript and ran MediaPipe's hand landmarker directly in the browser, on the GPU with a CPU fallback.

Before ~3.2 GB / hour of webcam frames uploaded per user
After 0 frames leave the device

9 gesture classes · 20 FPS inference cap · 5-frame stability threshold · matched the original classifier on 20,000 generated poses with 0 mismatches

02

A two-tier cache that stretches free API tiers

Every visitor to the same monument should share one upstream call. Requests hit an in-memory map, then a MongoDB cache, with in-flight de-duplication, stale answers served when a provider fails, and pooled API keys that rotate on rate-limit or auth errors.

03

Real-time 1v1 quiz duels

Two players join with a room code and race through ten rounds across four modes: flags, trivia, India-wide heritage and single-monument questions. Rooms live in memory, are swept every minute, and each socket is limited to 30 room actions per 10 seconds so no one can exhaust the server.
